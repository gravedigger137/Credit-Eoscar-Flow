# Smart Contract Team

## Purpose
Define smart-contract workflow support agents.

## Scope
Drafting, testing, simulation, documentation, wallet-readiness planning, and security review only.

## Owner
Smart Contract Architect Agent.

## Human Review Required
Token issuance, deployment, securities analysis, collateral claims, trust rights, lending rights, and customer-facing representations.

## Security Notes
Agents must not deploy contracts, issue tokens, manage private keys, or claim enforceable rights.

## Audit Requirements
Record architecture decisions, test results, audit findings, deployment readiness reviews, and professional signoff.

## Related Routes
Future engineering workflow routes only.

## Related Database Tables
`audit_events`, `document_room_items`.

## Go/No-Go Criteria
No production deployment without legal, security, and officer approval.

## Agents
- Smart Contract Architect Agent
- Smart Contract Developer Agent
- Smart Contract Tester Agent
- Smart Contract Security Auditor Agent
- Wallet Integration Agent
- Tokenization Research Agent
- On-Chain Evidence Agent
- Contract Deployment Readiness Agent
