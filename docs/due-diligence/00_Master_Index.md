# Due Diligence Binder - Master Index

## Overview
Central index for Infinite Arcadia / Credit-Eoscar due diligence. This binder organizes evidence and review status only.

## Purpose
Give management, attorneys, accountants, lenders, and investors a truthful map of organizational, legal, technology, compliance, finance, asset, and onboarding records.

## Architecture
Operational records map to `document_room_items`, `legal_instruments`, `collateral_assets`, `receivable_readiness_records`, `facility_readiness_checklist`, and `audit_events`.

## Dependencies
Source records, professional review, masked sensitive data, and manual lender-visibility approval.

## Folder Structure
Files `01` through `14` in this folder form the binder sections.

## Security
No secrets, SSNs, EINs, account numbers, bureau credentials, or customer PII should be committed.

## Maintenance
Update this index when sections are added, superseded, approved, or made lender visible.

## Related Documentation
`docs/Master-Asset-Register.md`, `docs/Credit-Facility-Readiness.md`, `docs/Security-And-Audit-Controls.md`.

## Required Documents
All binder sections require owner, review status, attorney/accountant review flag, version/date tracking, and lender/investor notes.

## Document Owner
Chief Admin / Officer Task queue.

## Review Status
Draft - attorney/accountant review required.
