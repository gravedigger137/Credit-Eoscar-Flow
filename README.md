# Credit Eoscar Flow

Full-stack credit operations platform with a React frontend, Express backend, PostgreSQL database, Drizzle ORM schema, authentication, billing hooks, AI integrations, file uploads, automation, reporting, and deployment infrastructure.

## Quick Start

```bash
cp .env.example .env
npm install
npm run db:push
npm run dev
```

Open `http://localhost:5000`.

## Deploy

Use `Dockerfile` and `docker-compose.yml` for self-hosted deployment, or deploy the Node app to any platform that supports Node.js 20 and PostgreSQL.

See `DEPLOYMENT.md` for the full setup.
