# Intellectual Property

## Overview
Software, algorithms, prompts, workflows, trade secrets, documentation, branding, marks, copyright records, and designs.

## Purpose
Track IP assets without overstating registration, ownership, assignment, or valuation.

## Architecture
Use `collateral_assets` for asset metadata and `document_room_items` for supporting evidence.

## Dependencies
Source code repositories, registration records, assignment documents, license terms, and attorney review.

## Folder Structure
Document Room categories: `IP Assets`, `Technology`, and `Lender Package`.

## Security
Do not disclose trade secrets, private prompts, source-code credentials, API keys, or customer PII.

## Maintenance
Update after major releases, registrations, assignment changes, license changes, or algorithm changes.

## Related Documentation
`docs/Master-Asset-Register.md`, `docs/Credit-Algorithm.md`.

## Required Documents
Repository evidence, copyright records, trademark records if any, assignment documents, architecture docs, version history.
