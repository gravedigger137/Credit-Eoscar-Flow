# Negotiable Instruments Workflow

## Purpose

Define documentation and workflow controls for negotiable-instrument records, including configurable references to applicable commercial law and user-entered terms.

## Scope

Covers intake, draft creation, party fields, principal/payment terms, governing law, status, review, execution tracking, version history, and audit logging.

## Applicable Module

Document Room, Legal Instruments, Credit Facility Readiness, future BrandonFintech commercial-document workflows.

## Required Controls

- Separate document generation from execution status.
- Require governing law selection.
- Track parties, amount, maturity, payment schedule, collateral reference, and status as user-entered terms.
- Keep UCC references configurable and attorney-reviewed.
- Require human approval before marking any instrument ready for external review.
- Preserve every generated version and audit event.

## Manual Tasks

- Confirm instrument type and governing jurisdiction.
- Review draft language with counsel.
- Verify execution, delivery, consideration, and recordkeeping requirements outside the app.
- Attach supporting evidence manually.

## External Dependencies

- Legal counsel.
- E-signature provider if electronic execution is used.
- Document storage and audit logs.

## Evidence Needed

- Draft instrument.
- Version history.
- Governing-law selection.
- Review approvals.
- Execution evidence, if executed.
- Audit trail.

## Status: Draft / Ready / Requires External Approval

Draft. Requires external legal review before use.

## Disclaimer

This documentation is not legal advice and does not determine whether any item is negotiable, enforceable, valid, perfected, or collectible.
