# Smart Contract Security Review

## Purpose
Provide a security review checklist for any future smart-contract work.

## Scope
Architecture, code, tests, wallets, deployment readiness, on-chain evidence, and tokenization research.

## Owner
Smart Contract Security Auditor Agent.

## Human Review Required
Legal, securities, tax, custody, fiduciary, lending, and insurance implications.

## Security Notes
Never commit private keys, seed phrases, deployment keys, RPC credentials, or wallet recovery data.

## Audit Requirements
Record test vectors, static analysis, manual review, approvals, and deployment block decisions.

## Related Routes
None currently.

## Related Database Tables
`audit_events`.

## Go/No-Go Criteria
Deployment is blocked until professional review, third-party audit where needed, and explicit officer approval.
